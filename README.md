# 荒野之间

Godot 2D 荒野生存项目。当前完成 P0–P5：基地采购、网格装载、随机荒野、身体 / 疾病、技能实践与学习、采集 / 伐木 / 捕鱼 / 陷阱、营地升级 / 料理 / 药剂制作、休息 / 睡眠、单机 7 日结算，以及真实双人 ENet 验证。下一阶段 P6 接入动物 AI、狩猎与战斗；完整 2–4 人合作生命周期仍待 P6.5。

## 启动

使用 Godot 4.7.2 打开 `project.godot`，按 **F5** 运行主场景。渲染器为 Compatibility。

- WASD：移动；Shift：快走 / 荒野冲刺，荒野消耗体力，耗尽时仍可慢走恢复。
- 靠近设施按 E，或点击底部按钮：打开补给站、仓库、训练场与出发点。K 随时查看技能；基地可用货币学习，荒野通过有效实践获得本分支点数解锁。
- Tab：打开 / 关闭库存；Esc：打开暂停或关闭面板。单机菜单暂停移动。
- 补给站：选择商品和数量，点击「购买」，物资入仓；选中仓库物资可出售，免费补给不可出售。
- 拖动物资整理或跨容器转移；R 旋转；Shift + 点击堆叠选择拆分数量，再拖到空格。拖到同类堆叠可合并。
- 装备可拖入主手、副手或护甲槽；同时检查占格、独立体积和总负重，不设初始件数上限。
- 开始整备前可输入地图种子，留空随机；同一引擎 / 生成器版本、同一种子复现初始世界。
- 点击「开始出发整备」，调整行装后「确认出发」；取消整备恢复整备前布局。免费工具也要装入行装，留在仓库不能在荒野使用。
- E：采集 / 伐木、泉水取水 / 饮用、营地休息 / 睡眠、篝火取火 / 添燃料及领取满包产出。动作执行中锁定随身库存与移动，可通过底部按钮取消。
- C / B：打开料理、取水和建造选择；营地需要木材 8 / 纤维 6，篝火需要石材 3 / 木材 2。建造自动选择附近合法空地。
- 鱼点：带钓具，用浆果或纤维作饵，基础 30 游戏分钟 / 体力 6 / 60% 成功率；开始即消耗饵，失败或取消不退饵。捕鱼 2 可选双份模式，捕鱼 3 缩短耗时。鱼点每 12 小时补 2，最多 6 份。
- K：九分支共 27 节点；每分支 100 经验产生 1 点，三级节点花费 1 / 2 / 3 点，或基地货币 300 / 600 / 1200，必须逐级学习。失败、放弃保留经验 / 节点 / 剩余点数；界面显示未解锁与条件原因。
- 陷阱：学习陷阱 1 / 2 后，C / B 制作小型套索 / 大型陷阱，在真实兔 / 野猪栖息地附近投浆果。每 6 / 8 游戏小时检查一次，成功占用至收取，三次成功后耗尽，可用纤维 2 维护。最多五个有效陷阱，缺猎物不消耗饵；P5 猎物为可保存的静态栖息实体，动态 AI、刷新与攻击将在 P6 接入。
- 营地：建造 1 / 3 可升级营地 2 / 3，扩至 3×3 / 4×4，回血 ×1.5 / ×2；扩地失败不耗材料。建造 2 可制作料理台 / 皮甲；料理 1 可炖食、医疗 1 可制草药药剂，均显示火源 / 清水 / 设施条件。可拆除建筑回收部分实际投入材料，公共箱须先清空。
- Tab：整理行装，选中食物进食；选中水壶可喝 0.25 / 0.5 L。进食耗时 1 分钟，再用 10 分钟消化。
- H 或「身体 / 疗养」：查看营养、症状、病程、药剂冷却、恢复与护甲系数；单机暂停，合作继续计时。带上绷带 / 草药药剂后，可在该面板的「治疗 / 营地行动」、C / B 或库存选中药品时治疗。绷带 1 / 5 分钟止血；药剂 1 / 10 分钟缩短肠胃病程 6 小时，生效后冷却 2 小时；条件不满足不消耗药品。衰弱须五项营养均 ≥30 连续 6 小时恢复。
- 地图概览：白点为当前位置，金点为出生点；水域及建筑占地不可通行。清洁泉水可不带容器直接饮用；生水、生食或腐坏食物会积累污染风险，达到阈值后每游戏小时由权威模拟判定肠胃不适。
- 靠近燃烧篝火可烤根茎或煮水；靠近营地可休息，或睡眠 1 / 2 / 4 / 8 小时跳时。跳时仍消耗营养、水分、燃料并推进腐坏 / 病程；出血、受伤、血量 / 水分危急会提前醒来。皮甲的物理减伤与耐久规则已实现；动物攻击和狩猎触发仍在 P6 接入。
- 累计生存 168 小时胜利并返仓，获得基础奖励 600 与探索 / 活动奖励；满仓物资在基地仓库领取。死亡或确认「放弃本局」失去随身物资，无成功奖励，基地货币 / 仓库保留。
- 旧 P1 占位和 P2 探索档保留原返回规则；新出发采用 P3 生存规则。

当前美术使用 Ninja Adventure（CC0）：四方向人物待机 / 行走、动态水面与篝火、地形 / 资源变体、基地建筑和库存图标。中文通过 Windows 系统字体显示，未复制或分发系统字体文件。详见 [接入记录](docs/11-ninja-adventure-art.md)。

正式路径为 `user://profile_identity.cfg` 与 `user://base_state.json`。除基地与完整世界外，保存身体、技能 / 点数 / 经验、料理实例品质、累计时间、动作 / 材料锁、营地等级 / 累计投入、陷阱 / 猎物 / 随机流、资源再生、工作点产出、返航待领取物资和结算收据。动作开始 / 完成、日切换、结算、每 2 分钟、暂停 / 失焦及正常退出保存。关键点写盘失败时不提交产出 / 奖励并冻结模拟重试。主档损坏尝试 `.bak`，未知总版本 / 子版本或其他玩家档案拒绝覆盖。版本仍为 1，旧档默认空技能并兼容原行动；测试只写 `.godot/verification/`。

## 双人合作验证

在基地点击「双人合作验证 · P3.5」，或打开 `scenes/coop.tscn` 按 F6。两端使用相同项目 / Godot 4.7.2。房主「新建验证房间」，队员填写房主 IP 与相同 UDP 端口后「连接 / 原身份重连」；本机双窗口用 `127.0.0.1`，默认端口 7000。两人都在线后由房主点击「两人出发」。

同机可在两个终端各启动一次：

```powershell
& '.\.tools\godot\Godot_v4.7.2-stable_win64.exe' --path . res://scenes/coop.tscn
```

合作个人菜单持续推进世界。WASD / Shift 移动，E 互动，C / B 建造与料理，Tab 行装，Esc 关闭菜单。营地和公共储物箱分别建造；箱子需要木材 6、纤维 4、30 游戏分钟、体力 4，1×1，占格库存 6×6 / 40 L。靠近箱子按 E 或 Tab，可在私人行装与公共箱间拖放、R 旋转、拆分 / 合并；远处箱子不能打开。

出发后新玩家不能加入。断线角色原地留存并持续模拟；未完成动作取消，不退时间 / 体力，保留未消耗材料。原成员以同一验证身份、端点与保存的凭据重连，沿用原位置、身体与物资，不重新领取装备。房主退出先保存并结束连接，下次可「恢复房主存档」。

本入口使用独立验证包、房主 / 队员身份和 `user://coop_validation_room.json`，不消耗永久基地物资、不发合作奖励。新房间每人有小刀、打火石、空水壶、钓具、16 木材、10 纤维、3 石材、3 干粮、2 绷带和 2 草药药剂，以及 600 独立验证货币；出发前按 K 可学习技能。旧房间恢复不重复补发装备或货币。技能与经验各自独立，保存在房主房间档案并随重连恢复；完整大厅 / 个人装载转移、四人、睡眠投票、死亡观战 / 尸体、跨设备个人永久成长 / 奖励与多人难度在 P6.5 完成。当前合作睡眠入口关闭；H / K / 库存菜单均不暂停世界。

## 验证

在项目目录运行：

```powershell
.\tools\verify_p5.ps1
.\tools\verify_p4.ps1
.\tools\verify_p35.ps1
.\tools\verify_p3.ps1
.\tools\verify_p2.ps1
.\tools\verify_p1.ps1
.\tools\verify_p0.ps1
.\tools\verify_ninja_art.ps1
```

本机 `.tools/godot/` 已从已有安装包解压 Godot 4.7.2，目录被忽略，不是项目发布内容。其他机器可指定编辑器路径：

```powershell
.\tools\verify_p3.ps1 -GodotPath 'C:\Tools\Godot\Godot.exe'
```

P3.5 有 80 项领域检查、22 项真实 UI 检查；两个实际 Godot 进程经 ENet 正常网络通过 61 项、100 ms / 1% 应用报文故障通过 63 项，覆盖并发物资、独立箱子耗材、角色留存 / 重连和房主保存结束。每次仅绑定回环随机端口，档案写入随机工作区目录；受限环境需要允许本机 UDP 回环。故障注入位于真实 ENet 上的应用报文层，包含一次额外定向库存请求丢失，不等于 OS 层 UDP 链路整形。证据见 [P3.5 报告](docs/13-p35-implementation.md)。

P4 新增 98 项领域、16 项 UI、正常 43 / 故障 44 项真实双进程检查，共 201 项通过；回归 571 项通过。覆盖病程 / 恢复、药品守恒 / 冷却 / 失败重试、身体存档、私人权限、离线病程及重连。图形隔离预览为 `tests/p4_preview.tscn`；详情与证据见 [P4 报告](docs/14-p4-implementation.md)。旧 P3 档案保留原身体和时间，并补齐默认疾病字段；未来身体子版本拒绝覆盖。

P5 新增 220 项领域、33 项 UI、正常 68 / 故障 70 项真实双进程检查，共 391 项通过，回归 772 项通过。覆盖技能 / 点数持久化、失败回滚、捕鱼耗饵 / 无产出无经验、陷阱实际猎物 / 数量上限、营地扩地、料理品质、并发与重连；定向丢失最后操作确认后可从结束收据恢复结果。Godot MCP 检查技能、营地、陷阱、食物与双人界面，最终运行 `errors: []`。隔离预览为 `tests/p5_preview.tscn`，详见 [P5 报告](docs/15-p5-implementation.md)。

P3 验证时间、身体、跳时、动作守恒、保存失败、运行中读档和结算去重；自动策略在 5 个种子上按默认资金、数值、材料和行动费用走完 168 小时。P2 回归包含 100 个地图种子，库存 / 基地 / 动画也有回归验证。自动策略加速模拟不等于正常速度人工试玩；本次网络验收也不代表完成四人、跨设备局域网或人工联机 7 日试玩。

已接入 Godot MCP，可运行隔离的 `tests/p3_preview.tscn` 检查生存、动作、背包和胜利画面；预览使用测试档案。编辑器调试构建可追加 `--debug-time-scale=10` 加速时间（1–100），不改变 7 日目标；正式发布构建不接受该参数。

双人界面预览使用 `tests/p35_preview.tscn`，第二角色是明确的显示夹具；真实通信单独由 `tests/p35_network.tscn` 双进程验证。P0–P3 / Ninja 检查拒绝非工作区验证档案参数，旧场景脚本即使未传参数也采用随机隔离身份。
