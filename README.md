# 荒野之间

Godot 2D 荒野生存项目。当前已实现 P0–P7：基地采购、网格库存、随机荒野、身体 / 疾病、技能、动物 / 战斗、营地 / 料理 / 治疗、单机 7 日循环，以及完整 2–4 人合作大厅、个人行装与成长交付、睡眠投票、尸体 / 观战和逐人结算。P8 已交付本机验证与 Windows x64 **0.2.0-rc1 候选包**，详见 [P8 报告](docs/19-p8-implementation.md)；性能目标、参考配置、跨设备 LAN 与人工七日仍待验收。

候选包位于 `build/WildBetween-0.2.0-rc1-windows-x64.zip`。完整解压后建议用 `Play-Isolated.cmd` 启动独立试玩档案，按 F1 阅读手册和调整界面音量；直接运行 EXE 会继续默认个人基地。详见 [试玩说明与已知范围](docs/20-candidate-player-guide.md)。

## 启动

使用 Godot 4.7.2 打开 `project.godot`，按 **F5** 运行主场景。渲染器为 Compatibility。

首次试玩按 **F1** 打开生存手册，查阅起步、配方、食物路线、治疗与合作规则。先在仓库把免费工具装包，再考虑采购 / 学习；整备点会提示实际携带情况。单机手册暂停，合作手册不暂停。结算后 F1 的「最近任务摘要」可再次查看个人奖励与返航物资统计。

- WASD：移动；Shift：快走 / 荒野冲刺，荒野消耗体力，耗尽时仍可慢走恢复。
- 靠近设施按 E，或点击底部按钮：打开补给站、仓库、训练场与出发点。K 随时查看技能；基地可用货币学习，荒野通过有效实践获得本分支点数解锁。
- Tab：打开 / 关闭库存；Esc：打开暂停或关闭面板。单机菜单暂停移动。
- 补给站：选择商品和数量，点击「购买」，物资入仓；选中仓库物资可出售，免费补给不可出售。
- 拖动物资整理或跨容器转移；R 旋转；Shift + 点击堆叠选择拆分数量，再拖到空格。拖到同类堆叠可合并。
- 装备可拖入主手、副手或护甲槽；同时检查占格、独立体积和总负重，不设初始件数上限。
- 开始整备前可输入地图种子，留空随机；同一引擎 / 生成器版本、同一种子复现初始世界。
- 点击「开始出发整备」，调整行装后「确认出发」；取消整备恢复整备前布局。免费工具也要装入行装，留在仓库不能在荒野使用。
- E：采集 / 伐木、泉水取水 / 饮用、营地休息 / 睡眠、篝火取火 / 添燃料及领取满包产出。动作执行中锁定随身库存与移动，可通过底部按钮取消。
- C / B：打开料理、取水和建造选择；营地需要木材 8 / 纤维 6，篝火需要石材 3 / 木材 2。建造自动选择附近合法空地。
- 鱼点：带钓具，用浆果或纤维作饵，基础 30 游戏分钟 / 体力 6 / 60% 成功率；开始即消耗饵，失败或取消不退饵。捕鱼 2 可选双份模式，捕鱼 3 缩短耗时。鱼点每 12 小时补 2，最多 6 份。
- K：九分支共 27 节点；每分支 100 经验产生 1 点，三级节点花费 1 / 2 / 3 点，或基地货币 300 / 600 / 1200，必须逐级学习。失败、放弃保留经验 / 节点 / 剩余点数；界面显示未解锁与条件原因。
- 陷阱：学习陷阱 1 / 2 后，C / B 制作小型套索 / 大型陷阱，在实际兔 / 野猪栖息地附近投浆果。每 6 / 8 游戏小时检查一次，成功占用至收取，三次成功后耗尽，可用纤维 2 维护。最多五个有效陷阱，缺猎物不消耗饵，与狩猎共用实际动物，不能重复获取同一猎物掉落。
- 左键：主手装备小刀 / 斧 / 弓，向鼠标方向攻击。刀 14 伤害 / 体力 4、斧 22 / 7，近战一格；弓需狩猎 1 和箭，30 伤害 / 体力 6，射程八格。攻击磨损武器 1，射空也耗箭，无效命中不获经验；命中 / 受伤显示反馈，击杀自动入包，满包产出留工作点。
- 兔警觉逃跑，野猪受击反击，狼感知追击；动物不穿水面 / 建筑，离栖息点十六格返回，每日视野外有界补充。狩猎 2 显示实际足迹 / 栖息信息，狩猎 3 击杀额外肉 1。首六小时出生区保护仍生效；受到物理攻击可能出血，带绷带处理后再睡眠。
- 营地：建造 1 / 3 可升级营地 2 / 3，扩至 3×3 / 4×4，回血 ×1.5 / ×2；扩地失败不耗材料。建造 2 可制作料理台 / 皮甲；料理 1 可炖食、医疗 1 可制草药药剂，均显示火源 / 清水 / 设施条件。可拆除建筑回收部分实际投入材料，公共箱须先清空。
- Tab：整理行装，选中食物进食；选中水壶可喝 0.25 / 0.5 L。进食耗时 1 分钟，再用 10 分钟消化。
- H 或「身体 / 疗养」：查看营养、症状、病程、药剂冷却、恢复与护甲系数；单机暂停，合作继续计时。带上绷带 / 草药药剂后，可在该面板的「治疗 / 营地行动」、C / B 或库存选中药品时治疗。绷带 1 / 5 分钟止血；药剂 1 / 10 分钟缩短肠胃病程 6 小时，生效后冷却 2 小时；条件不满足不消耗药品。衰弱须五项营养均 ≥30 连续 6 小时恢复。
- 地图概览：白点为当前位置，金点为出生点；水域及建筑占地不可通行。清洁泉水可不带容器直接饮用；生水、生食或腐坏食物会积累污染风险，达到阈值后每游戏小时由权威模拟判定肠胃不适。
- 靠近燃烧篝火可烤根茎或煮水；靠近营地可休息，或睡眠 1 / 2 / 4 / 8 小时跳时。跳时仍推进身体、燃料、腐坏、疾病和动物；近处危险按营地等级有受扰风险，真实攻击必定唤醒，未推进的睡眠时间停止。皮甲减免 35% 物理伤害、命中磨损 2，归零失效；出血 / 脱水仍绕过护甲。
- 累计生存 168 小时胜利并返仓，获得基础奖励 600 与探索 / 活动奖励；满仓物资在基地仓库领取。死亡或确认「放弃本局」失去随身物资，无成功奖励，基地货币 / 仓库保留。
- 旧 P1 占位和 P2 探索档保留原返回规则；新出发采用 P3 生存规则。

当前美术使用 Ninja Adventure（CC0）：四方向人物待机 / 行走、动态水面与篝火、地形 / 资源变体、基地建筑和库存图标。中文通过 Windows 系统字体显示，未复制或分发系统字体文件。详见 [接入记录](docs/11-ninja-adventure-art.md)。

正式个人路径为 `user://profile_identity.cfg` 与 `user://base_state.json`。保存基地、完整世界、身体 / 技能 / 随机流、动作 / 预留、设施 / 动物、返航待领取物资与收据。关键点写盘失败不提交产出 / 奖励，并冻结模拟重试。P6.5 增加完整 `.journal` 与 `.commit`：主档损坏从同一完整提交恢复，避免退回旧物资快照；不能校验的日志保留并停止恢复。旧档尚未建立提交日志时仍兼容 `.bak`，未知总版本 / 子版本或其他玩家档案拒绝覆盖。总版本仍为 1，新增合作子版本；自动验证使用 `.godot/verification/` 隔离路径，测试隔离修正记录见 [P6.5 报告](docs/17-p65-implementation.md)。

UI 使用同包木质九宫格和四种按钮状态，搭配森林绿底色、金色标题与紧凑状态条。库存、身体、营地和技能居中显示；长内容滚动，技能按窗口宽度切换列数，合作工具栏在小窗口换行。详见 [UI 改版与预览](docs/16-ui-redesign.md)。

## 2–4 人合作

在基地点击「2–4 人合作」，或打开 `scenes/coop_full.tscn`。两端使用相同工程与 Godot 4.7.2，网络协议 / 内容不兼容会拒绝连接。默认 UDP 7000；同机使用 `127.0.0.1`，局域网填写房主 IP。

1. 点击「基地补给 / 行装」购买并把物品从永久仓库放进背包 / 装备槽；「基地学习」使用个人货币学习。
2. 房主新建合作房间，队友连接；每人点击「提交个人行装」，等待房主确认后点击「准备」。
3. 房主点击「全员出发」，全体完成地图加载后统一开始计时。出发人数固定，资源 / 危险温和增加，途中仅原成员可重连。
4. Tab 整理私人背包与附近公共箱 / 尸体。工具栏可选择附近公共箱作为建造 / 制作材料源；「赠送选中实例」需对方明确接受，发送前在行装中选中物品。
5. 睡眠选择 1 / 2 / 4 / 8 小时，全体在线存活者同意；30 现实秒未通过则取消。受伤、身体危急、附近威胁、成员断线 / 重连 / 死亡中断全体跳时。
6. 死亡后观战、无复活，物资留在唯一尸体。到期存活者独立获奖，全部角色死亡则失败；个人结果写盘后可「返回单机」查看基地物资 / 技能。

菜单不暂停世界。断线角色原地持续模拟，不返还或补发装备；房主主动离开保存并结束房间。大厅和加载屏障解除前取消会退回原行装；已经开始的世界可在原房主选择对应存档恢复。完整房间逐个保存在 `user://coop_rooms/`，不会因新建房间覆盖旧交付记录。行装 / 永久成长同步未完成时，个人档案保持托管，须恢复原房间核对。

同机多窗口必须使用不同身份，下面分别创建两份独立试玩档案，不接触正式基地：

```powershell
& '.\.tools\godot\Godot_v4.7.2-stable_win64.exe' --path . res://scenes/coop_full.tscn -- --coop-profile=res://.godot/verification/manual-a.cfg --coop-room=res://.godot/verification/manual-a-room.json
& '.\.tools\godot\Godot_v4.7.2-stable_win64.exe' --path . res://scenes/coop_full.tscn -- --coop-profile=res://.godot/verification/manual-b.cfg --coop-room=res://.godot/verification/manual-b-room.json
```

首版为好友合作信任模型，提供局域网 / IP 直连；平台邀请、中继、专用服务器、房主迁移仍不在本版范围。四进程自动验证、日志恢复与已知范围见 [P6.5 报告](docs/17-p65-implementation.md)。

## 独立双人回归入口

在完整合作大厅点击「双人独立验证入口」，或打开 `scenes/coop.tscn` 按 F6。此模式保持 P3.5–P6 的独立回归语义。房主新建验证房间，队友填写房主 IP 和相同端口连接；两人在线后房主「两人出发」。

同机可在两个终端各启动一次：

```powershell
& '.\.tools\godot\Godot_v4.7.2-stable_win64.exe' --path . res://scenes/coop.tscn
```

合作个人菜单持续推进世界。WASD / Shift 移动，E 互动，C / B 建造与料理，Tab 行装，Esc 关闭菜单。营地和公共储物箱分别建造；箱子需要木材 6、纤维 4、30 游戏分钟、体力 4，1×1，占格库存 6×6 / 40 L。靠近箱子按 E 或 Tab，可在私人行装与公共箱间拖放、R 旋转、拆分 / 合并；远处箱子不能打开。

出发后新玩家不能加入。断线角色原地留存并持续模拟；未完成动作取消，不退时间 / 体力，保留未消耗材料。原成员以同一验证身份、端点与保存的凭据重连，沿用原位置、身体与物资，不重新领取装备。房主退出先保存并结束连接，下次可「恢复房主存档」。

本入口使用独立验证包、房主 / 队员身份和 `user://coop_validation_room.json`，不消耗永久基地物资、不发合作奖励。新房间每人有小刀、打火石、空水壶、钓具、16 木材、10 纤维、3 石材、3 干粮、2 绷带和 2 草药药剂，以及 600 独立验证货币；出发前按 K 可学习技能。旧房间不重复补发物资。成长只保存在该验证房间；睡眠入口保持关闭，H / K / 库存均不暂停。完整合作功能请使用上面的四人入口，两种档案不能混读。

P8 本轮 1794 项检查通过，另有五个种子按默认速度、合法睡眠完成 168 小时自动生存；四进程回环包含 150 ms / 每 20 个应用报文丢 1 个的故障验证。发布 EXE 已通过单机冒烟和双进程重连 / 逐人结算；其结算使用最后一分钟夹具，完整发布包人工七日仍待验收。1080p 建筑压力样本平均单机 59.10 FPS / 四人权威加房主视图 47.22 FPS，部分同步保存超过 100 ms，不能标记全部性能通过。详情、复现命令与证据见 P8 报告。

导出与打包使用 `tools/build_windows.ps1`、`tools/verify_export.ps1`、`tools/package_windows.ps1`；默认不执行五种子长测，需追加 `verify_p8.ps1 -RealTimeSeeds`。交付包排除 QA 档案，附许可与 SHA256 清单。

本机 `.tools/godot/` 已从已有安装包解压 Godot 4.7.2，目录被忽略，不是项目发布内容。其他机器可指定编辑器路径：

```powershell
.\tools\verify_p3.ps1 -GodotPath 'C:\Tools\Godot\Godot.exe'
```

P3.5 有 80 项领域检查、22 项真实 UI 检查；两个实际 Godot 进程经 ENet 正常网络通过 61 项、100 ms / 1% 应用报文故障通过 63 项，覆盖并发物资、独立箱子耗材、角色留存 / 重连和房主保存结束。每次仅绑定回环随机端口，档案写入随机工作区目录；受限环境需要允许本机 UDP 回环。故障注入位于真实 ENet 上的应用报文层，包含一次额外定向库存请求丢失，不等于 OS 层 UDP 链路整形。证据见 [P3.5 报告](docs/13-p35-implementation.md)。

P3 自动策略在 5 个种子上按默认资金、数值、材料和费用走完 168 小时；P2 包含百种子与定向检查。自动策略不等于正常速度人工试玩；四人测试是同机回环并布置最后一分钟触发结算，不代表跨设备 LAN 或人工合作七日验收。

已接入 Godot MCP，可运行隔离的 `tests/p3_preview.tscn` 检查生存、动作、背包和胜利画面；预览使用测试档案。编辑器调试构建可追加 `--debug-time-scale=10` 加速时间（1–100），不改变 7 日目标；正式发布构建不接受该参数。

双人界面预览使用 `tests/p35_preview.tscn`，第二角色是明确的显示夹具；真实通信单独由 `tests/p35_network.tscn` 双进程验证。P0–P3 / Ninja 检查拒绝非工作区验证档案参数，旧场景脚本即使未传参数也采用随机隔离身份。
