# 2D 荒野生存：首版设计基线

更新：2026-10-15。设计版本：0.2。状态：P0–P7 已实现，单机 7 日循环与完整 2–4 人合作生命周期可玩。合作已接入实际个人行装 / 成长、全员准备 / 加载、公共材料 / 赠送、睡眠投票、死亡 / 尸体 / 观战、原成员重连和逐人结算。当前交付见 [P7 内容整合报告](18-p7-implementation.md)，合作领域见 [P6.5 报告](17-p65-implementation.md)，此前见 [P3](12-p3-implementation.md)、[P3.5](13-p35-implementation.md)、[P4](14-p4-implementation.md)、[P5](15-p5-implementation.md)、[P6](16-p6-implementation.md) 报告。最终性能、跨设备与导出继续按 P8 验收。

用户已授权确定全部待定项。本文是实现基线；规则追溯见 [已确定设计决策](03-design-decisions.md)，具体初始数值见 [配置表](05-initial-balance.md)，代码约束见 [工程规范](04-engineering-guidelines.md)。平衡配置可经验证调整，不保留设计占位项。

用户随后要求加入联机并确认 8 项合作规则。单机基线保留；合作暂停、死亡、共享、存档与结算按 [联机设计](06-multiplayer-design.md) 执行。

## 1. 定位与循环

Windows 10 / 11 x64 键鼠、俯视角像素风，资源取舍、身体管理与简洁动作狩猎。提供单机和 2–4 人合作，无 PvP；先验证单机再整合联机，目标为累计存活 7 个游戏日。

```text
永久基地：买物资、管理仓库、学习技能
 → 准备：按网格空间、体积和负重装载，无物品件数上限
 → 生成荒野：验证地图和出生点后投放
 → 探索：获取食物与水、取火、建营地、管理体力与伤病
 → 存活 168 游戏小时：发奖励、随身物资返仓、回基地
 → 本人血量归零：单机失败返基地；合作尸体留存 / 观战，队友继续
```

两个世界场景分别为永久基地、荒野。临时营地直接存在荒野，不创建第三种独立世界；准备、技能、身体详情和结算均为 UI。

## 2. 永久基地与出发

基地包含商店、仓库、学习和出发入口，不推进荒野时间。首次建档获得 600 货币，商店固定目录，不做刷新或动态涨价。

购买事务先校验货币与入仓条件，再扣款入仓；失败不扣钱。出发事务把仓库物品转入单局，地图生成和投放失败全部退回原状态，投放成功后正式承担丢失风险。

每局提供固定标准背包；免费小刀、打火石和空水壶仅在所有归属库存没有对应免费实例时补齐，不可出售 / 拆解。免费补给仍有重量、占格，失败仍丢失。保证零货币能够再次出发，也保证裸装有清洁泉水、食物与落枝可获得。

工具磨损归零不能继续使用，但物品保留；非免费工具可基地修理。物资售价、耐久、重量、体积和功能都来自稳定配置 ID。

## 3. 网格库存与携带

物品具有占格宽高、单位重量 kg、外部体积 L；容器同时限制几何空间和升数容量。标准背包 8×6 / 30 L，仓库 12×10 / 120 L，营地箱 6×6 / 40 L。

支持拖放、90° 旋转、落点预览、拆分与合并。放置不可越界或重叠；预览与实际提交共用校验，失败保留源位置、数量和货币。

总携带重量包含背包空重 0.8 kg、背包内容、主副手和护甲、容器内部水。18 kg 起软惩罚，30 kg 硬上限，最大减速 35%、高强度体力开销 +75%。没有件数限制。

主手容纳工具 / 武器，副手容纳工具 / 水容器，护甲占一个独立槽；穿戴物不占背包格子和内部升数，但计入总负重。标准背包不可堆叠，不允许备用背包或储物箱嵌套。

堆叠固定占格，重量与内容体积按数量累计。不同耐久 / 内容的工具不堆叠；食物合并保留最早到期时间。金属水壶外部体积固定 1.2 L，内部最多 1 L，水增加重量，不重复增加背包外部占容体积。

## 4. 时间、暂停与行动

1 现实秒 = 120 游戏秒，1 日自然推进 12 分钟；累计存活 168 小时获胜。基地、加载、生成不推进任务时间。

身体 / 世界按 1 游戏分钟步长推进，动作完成、危险事件、目标时间处拆步，不跳过边界；角色移动与战斗独立更新并提交即时事件。

单机操作面板、Esc 和失焦暂停，整理和选配方不耗时，提交动作恢复。合作个人面板不暂停共享世界，身体、腐坏和危险继续。实际制造 / 治疗 / 劳动在两种模式都消耗时间和体力。

动作开始检查技能、工具、材料、空间与体力，锁定材料并一次扣动作体力，过程中按劳动速率消耗营养 / 水分；成功提交材料消耗、产物和经验。中断释放未消耗材料，不退体力或时间；射箭和投饵使用时立即消耗，不可取消返还。

制造产物无法入包时进入当前工作点可领取输出区，不丢失、不重复发放；只有实际放入随身库存的物品才能带回基地。

睡眠可选择 1 / 2 / 4 / 8 小时，通过同一套模拟推进营养、水分、疾病、腐坏、燃料、陷阱和动物事件。受攻击、出血、血量 ≤20 或水分 ≤20 时提前醒来，不只增加天数。

合作睡眠需全体在线存活者同意相同时长，跳时仍模拟断线角色，任一存活角色遇威胁或危急状态时中断。个人失焦不能暂停其他玩家。

## 5. 角色属性

| 属性 | 职责 |
| --- | --- |
| 血量 | 当前 / 最大均初始 100；归零死亡，单机结束本局，合作进入观战 |
| 护甲 | 装备提供物理减伤，皮甲 35%，减伤上限 60%；不能抵消疾病 / 脱水 / 出血 |
| 五类营养 | 碳水、脂肪、蛋白质、矿物质、维生素，分别 0–100 |
| 水分 | 独立 0–100，饮水补充，时间与活动消耗，持续缺水损害健康，归零扣血 |
| 体力 | 当前 / 最大 0–100，短期动作储备，冲刺 / 劳动 / 战斗消耗，低强度和休息恢复 |
| 健康 | 0–100，营养不足、卫生与伤病影响，修正恢复与疾病易感性，不直接覆盖血量 |
| 技能 | 开放高级互动、提高效率，有效实践获经验 / 点数或基地付费学习 |

每局身体重置满值、清除疾病，不跨局收治疗费；永久保留货币、仓库未带出物品、技能节点、经验和未使用点数。

营养采用游戏化储备，不模拟真实人体；低于 30 提示、持续低于 20 影响健康，严重能量不足扣血。食物在 10 游戏分钟消化，过量封顶，不加入首版营养过量疾病。

水源分清洁泉水和河湖生水：泉水可就地直饮，河湖水取入容器后煮沸；生饮和生食增加污染风险。基础煮水不需要高级技能。0.5 L 清水增加水分 25，水壶与水量遵守容量 / 重量限制。

体力与长期营养分开计算。营养、水分、健康修正恢复，负重增加高强度体力成本。体力耗尽保留慢走、取水、饮食和休息，防止恢复死锁。公式和具体行动费用见配置表，不在多个系统重复扣同一动作费用。

## 6. 疾病与疗养

首版有出血、肠胃不适、营养衰弱，另有脱水状态。界面显示症状、来源线索、持续时间与处理办法。

出血由有效物理命中概率触发，绷带止血；肠胃不适由污染风险和健康修正决定，草药制剂缩短病程；持续营养低值造成衰弱，改善饮食并保持一段时间后恢复。脱水按水分规则处理，不重复扣费。

低健康首先影响恢复和易感性；健康归零本身不直接死亡。状态影响集中求和和限制范围，避免多个脚本对同一病因重复处罚。

休息 / 疗养在安全环境中恢复体力，满足营养和水分条件时缓慢恢复健康与血量。营地提高恢复效率但不能代替食物、饮水或医疗。

## 7. 技能成长

九分支为采集、伐木、取火、捕鱼、狩猎、陷阱、建造、料理、医疗，各 3 节点，共 27 个。每 100 分支经验获得 1 分支点，顺序解锁成本为 1 / 2 / 3 点。

基地可支付 300 / 600 / 1200 解锁相同节点，仍需前置节点，不消耗点数、不赠点或经验、不退已花点数，重复解锁不扣费。

只有实际有效产出或治疗才给经验，失败为 0；空挥工具、打开面板、无资源捕鱼不获点，重复拆建经验受每局次数限制。所有经验和未使用点数失败后保留。

基础采集、低效伐木、取火、煮水、烤食、简易营地、箱、休息、近战不锁技能；弓、陷阱、高级料理、医疗配方、营地升级需要对应节点。工具、技能、资源和环境分别检查，明确显示缺少条件。

## 8. 荒野地图与资源

有限地图 128×128，森林 / 草地 / 水域约 50 / 30 / 20%，使用噪声地形、连通区域检查和独立随机流投放资源。

出生从合格候选随机选择，须处主连通区、可离开；到食物 / 木材 / 水源最短可达距离分别 ≤8 / 10 / 12 格，附近有浆果与根茎两条基础食物路径、可直饮泉水和落枝。不能靠直线距离判资源可达。

初始危险动物距出生 ≥30 格，半径 6 格出生安全区前 6 游戏小时禁止危险动物进入和刷新。地图最多重试 5 次，失败使用满足相同检查的安全模板。

树石、落枝、纤维、草药不再生；浆果 24 小时、根茎 48 小时恢复；鱼点 12 小时补充但封顶；动物按栖息区、视野与数量限制补充。具体初始数量见配置表。

固定引擎 / 生成器版本和种子可复现初始地图。存档同时保存完整地图与变更，随机种子 / 状态保留整数精度，不能只凭种子依赖跨版本重建。

## 9. 活动与临时营地

| 活动 | 核心行为 |
| --- | --- |
| 采摘 / 采集 | 获取浆果、根茎、纤维、草药、石材和落枝，消耗时间 / 体力 |
| 伐木 | 小刀低效、斧头高效，获得木材并磨损工具 |
| 取火 | 篝火需燃料与点燃，打火石可靠，无工具钻木有失败率 |
| 料理 | 烤食 / 煮水基础可做，炖食需技能和料理台；逐份消耗时间 |
| 建造 / 升级 | 三级营地、箱、篝火、料理台；材料、空间和技能条件，升级收益可见 |
| 捕鱼 | 岸边鱼点、钓具与鱼饵，有成功率与存量限制 |
| 狩猎 | 近战 / 弓箭捕猎兔、野猪、狼，有反击风险与肉皮收益 |
| 陷阱 | 对应栖息区、定时检查、真实动物捕获、诱饵 / 耐久维护 |
| 疗养 | 休息、睡眠、绷带 / 草药治疗，受危险或身体状态打断 |

营地 1 / 2 / 3 占地 2×2 / 3×3 / 4×4，回血系数 1 / 1.5 / 2，降低睡眠受扰但不免疫真实攻击或身体损耗。建筑不能放水面、重叠或封死唯一通道。

可拆除设施返还实际投入可回收材料的 50% 向下取整，不返燃料 / 食物 / 已用饵；箱须先清空，陷阱回收再按剩余耐久比例计算，避免拆建套利。

## 10. 战斗

鼠标朝向近战和弓箭，无连招 / 翻滚 / 枪械 / 部位伤害。兔逃跑，野猪受击反击，狼主动警觉追击，离开栖息区过远返回。

工具攻击与装备减伤有清晰反馈，耐久归零后功能失效。动物掉落只结算一次，陷阱不能凭空生成猎物。耗尽体力无法攻击但可移动和恢复。

## 11. 胜负、经济与返仓

达到 168 小时且对应步伤害结算后血量大于 0，冻结模拟并成功返航；同刻归零的玩家不成功。单机死亡结束本局，合作全员死亡才提前结束。任务结束取消未完成动作，释放未耗材料，不生成未完工产物。

成功奖励基础 600，可加探索 0–100、九类首次有效活动 0–90；失败无奖励。单机按任务 ID 去重，合作按任务 / 玩家 / 事件组合去重，避免漏发其他队员或重复领奖。

胜利返还背包与装备槽中的剩余物资，保留数量、耐久、新鲜度、容器内容；地面、营地箱和设施不返。优先自动入仓，放不下存入无到期的持久化待领取区，必须入仓后才能使用 / 出售，不能当随身背包。

单机失败清除本局物资、地图和营地；合作死亡无复活、转观战，物资进入队友可搜取尸体，世界到期或全员死亡结束。基地货币、未带出的物资和永久成长保留。新一局初次投放重置身体，重连不重置。

合作每名存活者独立领基础 / 个人加奖，经验归执行者；公共箱开放，私人背包仅本人操作，可主动赠送。房主保存世界、个人保存基地成长，跨端提交 / 收据去重；房主离开保存并结束房间。

## 12. 技术结构与存档

已核实本机可用版本 `4.7.2.stable.official.ed1daf0bf`，使用类型化 GDScript。P0 从已有安装包解压本地验证引擎，未修改系统 PATH；验证见 [P0 报告](07-p0-implementation.md)。

首版使用 Compatibility，P0 已切换工程配置并用实际图形窗口验证；该选型适合无需高级渲染特性的 2D 项目，参考 [Godot 官方渲染器文档](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html)。

地形分层使用 TileMapLayer，静态物品 / 配方 / 技能使用 Resource，实例状态独立。参考：[官方 TileMaps 文档](https://docs.godotengine.org/en/stable/tutorials/2d/using_tilemaps.html)、[Resources 文档](https://docs.godotengine.org/en/stable/tutorials/scripting/resources.html)。

模块职责按工程规范固定，UI → 应用服务 → 领域规则与数据；显式依赖、局部信号、统一校验，避免万能 AutoLoad。脚本职责、公开接口、单位、关键算法与边界必须附说明注释。

单机一个 user:// 存档槽，每 2 现实分钟、关键转换、日切换和正常退出保存，允许继续，无历史回档；临时写后替换，保留损坏恢复备份，永久 / 单局 / 结算同事务。合作房主世界 / 个人档案分离，以跨端记录和收据去重，不把不同电脑存档视为同一个本地文件事务。

存档覆盖货币、技能、任务 ID、地图、随机状态、角色全部属性、物品布局 / 旋转 / 容器内容、动物、资源、建筑、陷阱、火源、消化 / 腐坏 / 病程、动作与材料锁定。恢复必须校验稳定 ID、数量和容量；同任务不可重复发钱或物资。

## 13. 完整首版与范围

完整首版覆盖原始活动、网格库存、重量 / 体积、饮水 / 体力、疾病、永久技能、两种学习、返航 / 存档及 2–4 人合作。P3 为单机原型，P3.5 双人验证，P6.5 完成合作生命周期，P7 整合全部内容。

首版只有昼夜视觉，排除无限世界、动态天气、季节、体温、多可选主角、复杂生态、基地装修与医学模拟。联机初版房主承载、局域网 / IP 直连；邀请、中继、专用服务器、房主迁移留待后续版本。性能 / 网络指标尚无实测结果。
