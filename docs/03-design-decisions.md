# 2D 荒野生存：已确定设计决策

更新：2026-10-13。基线版本：0.2，保留单机并增加合作模式。

用户已授权「确定所有待定项」。原待定项成为首版约束；当前没有未决核心设计项，数值可经验证调整。P0–P5 已实现，双人验证不代表完整四人生命周期完成，当前证据见 [P5 报告](15-p5-implementation.md)，此前见 [P3](12-p3-implementation.md)、[P3.5](13-p35-implementation.md)、[P4](14-p4-implementation.md) 报告。

用户随后要求加入联机并确认 N01–N08，相关覆盖按本文件及 [联机设计](06-multiplayer-design.md) 执行，原「无联机」范围已修订。

关联：[设计基线](01-game-design.md)、[执行计划](02-execution-plan.md)、[工程规范](04-engineering-guidelines.md)、[数值与内容配置](05-initial-balance.md)。

## 此前用户明确确认的规则

| ID | 设计项 | 规则 |
| --- | --- | --- |
| C01 | 视角与控制 | 俯视角自由移动 |
| C02 | 单机时间与暂停 | 实时探索；背包 / 制作菜单暂停；睡眠可跳时；合作按 N03 |
| C03 | 失败损失 | 本局携带、采集物资全部失去 |
| C04 | 失败保留 | 基地货币与永久技能保留 |
| C05 | 首版目标 | 7 个游戏日，可配置 |
| C06 | 初始物资限制 | 取消 5 件上限，只按空间和负重限制 |
| C07 | 物品存放 | 物品有重量、体积，采用华容道式网格存放 |
| C08 | 成长持久化 | 有效实践经验和未使用技能点永久保留，失败不清除 |
| C09 | 胜利物资 | 随身剩余物资按数量、耐久和新鲜度返仓；营地留存物资不带回；奖励独立发放 |
| C10 | 营养 | 五类游戏化营养储备 / 充足度，持续不足影响健康和疾病 |
| C11 | 新增身体属性 | 首版包含饮水需求与体力 |
| C12 | 代码质量 | 尽量低耦合、高内聚，附说明注释 |

## 固定的工程与交互选择

| 项目 | 决定 |
| --- | --- |
| 技术目标 | Godot 4.7 系列、类型化 GDScript；P0 实测 4.7.2.stable.official.ed1daf0bf |
| 渲染 | P0 已将 Forward Plus 切换为 Compatibility 并验证实际图形渲染 |
| 场景 | 基地、荒野两种世界场景；准备、技能、身体详情、结算为 UI；临时营地在荒野 |
| 模拟 | 身体 / 世界以 1 游戏分钟固定步长推进，跨事件边界拆步；移动 / 战斗独立更新并提交事件 |
| 输入 | WASD 移动，Shift 冲刺，E 交互，Tab 背包，C 制作，B 建造，H 身体，K 技能，R 旋转，左键拖放 / P6 攻击，Esc 暂停 |
| 暂停 | 单机面板、Esc、失焦暂停；合作个人菜单不暂停，睡眠全员投票；Esc 取消拖拽保留位置 |
| 中断 | 开始锁材料并扣动作体力，成功消耗材料；中断释放未耗材料，不退体力 / 时间；射箭、投饵使用时立即消耗 |
| 耐久 | 工具 / 护甲 0–100，归零不可使用但物品保留，可付费修理 |
| 内容 | 固定首批商品、资源、食物、配方、27 技能节点和 3 类动物，见配置表 |
| 性能目标 | 四核 CPU、8 GB RAM、OpenGL 3.3 兼容显卡；1080p 60 FPS、生成 ≤ 3 秒、存档主线程阻塞 ≤ 100 ms；是验收目标而非实测结论 |
| 流程 | 单工作区顺序交付，加入 P3.5 双人验证 / P6.5 四人整合，提供说明、注释、验证；不自动派生并行代理，不承诺日历工期 |

Compatibility 适用于无需高级渲染功能的 2D 项目，参考 [Godot 官方渲染器文档](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html)。
