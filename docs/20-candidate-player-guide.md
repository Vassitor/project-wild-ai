# 荒野之间 0.2.0-rc1 · Windows 试玩说明

这是首个 Windows x64 候选包，使用 Godot 4.7.2 / Compatibility。完整解压 ZIP 后运行；EXE 和 PCK 必须放在同一目录。无需安装 Godot 编辑器。

## 启动与档案

建议先双击 `Play-Isolated.cmd`：使用专属 `candidate_rc1_profile.cfg` 与对应基地档案，首次获得默认新角色物资，不覆盖原有基地。再次使用此启动器会继续这份试玩档案。

直接双击 `WildBetween.exe` 会继续原来的正式个人档案；`WildBetween.console.exe` 是同一游戏的控制台入口，便于收集错误信息。

默认档案位于 `%APPDATA%\Godot\app_userdata\Project_Wild_AI\`。合作房间在其 `coop_rooms` 目录。退出游戏后备份整个目录；恢复时保留身份、主档、`.bak`、`.journal`、`.commit` 及房间目录的对应关系。遇到保存错误按界面提示重试，保持原文件供排查。

## 第一局

1. 按 **F1** 阅读起步、配方、治疗与合作规则。底部可调整界面音效音量并试听，设置随当前身份保存；音效为按钮点击提示。
2. 基地靠近设施按 **E**。在仓库把免费小刀、水壶和打火石放进行装，按需购买干粮、绷带等。物资受网格、独立体积和负重限制，没有件数上限。
3. 到出发点开始整备，检查实际携带，再确认出发。默认目标是 **7 个游戏日**；探索时 1 现实秒约为 2 游戏分钟，合法睡眠可以跳时。
4. 找到清泉补水，采浆果、根茎和材料，建临时营地与篝火。进食、饮水、疗养和睡眠都推进身体与世界。携带食物后留意营养，受伤出血后及时使用绷带。
5. 生存到期自动结算返航。存活者获得奖励，随身物资返仓，满仓部分在基地待领取；营地物资留在荒野。死亡或放弃损失本局物资，基地货币和永久成长保留。

| 操作 | 按键 / 方式 |
| --- | --- |
| 移动 / 冲刺 | WASD / Shift；冲刺消耗体力 |
| 就近交互 | E |
| 行装 / 旋转 / 拆分 | Tab / R / Shift 点击堆叠 |
| 身体、治疗 / 技能 | H / K |
| 建造、料理、疗养 | C 或 B |
| 按方向攻击 | 主手装备刀、斧或弓后左键；弓需技能和箭 |
| 手册、音量 / 关闭面板 | F1 / Esc |

单机个人菜单暂停；合作菜单继续模拟。长动作开始后关闭单机面板才能继续执行。

## 合作连接

两台设备完整解压**同一份候选 ZIP**，各自运行 `Play-Isolated.cmd` 并在基地进入「2–4 人合作」。房主新建房间，队友输入房主的局域网 IPv4 地址与相同端口，默认 **UDP 7000**。Windows 如提示网络访问，应允许当前私人局域网连接。

每人先整理个人行装，再「提交个人行装」并「准备」；房主等待全员到齐后统一出发。个人背包私人、公共箱公开，赠送需对方接受。睡眠需所有在线存活者同意，威胁、伤害或成员状态改变会中断。死亡后观战、无复活，尸体可搜取；中途只允许原成员重连。房主离开保存并结束房间，恢复时选择原房间。

当前提供局域网 / IP 直连，公网连通取决于网络环境；无平台邀请、中继或房主迁移。同机开多个窗口须给每个窗口使用不同 `--profile-store` 身份路径，不能同时写同一个个人档案。

## 已知范围

- 本机已通过百种子地图、五种子默认速度自动生存、四进程合作回环和发布 EXE 双进程检查。自动策略使用正常移动、材料和合法睡眠；它不代表人工七日体验。
- 发布 EXE 已验证基地、出发、荒野显示、最后一分钟夹具触发结算、存档、合作重连和逐人结算；发布包完整七日人工试玩、跨设备 LAN 仍待验收。
- 当前压力场景仍有保存卡顿；四人房主平均帧率未稳定达到 60 FPS，部分保存超过 100 ms。下一轮优先优化保存与房主帧时间。未在 8 GB 参考配置上验收。
- 中文使用 Windows 的 Microsoft YaHei / SimHei 系统字体；本包不分发字体文件。当前声音仅为可调音量的界面提示，未提供环境声或背景音乐。

## 版本与许可

本版新增 Windows 导出、发布包内容指纹、界面音效 / 音量持久化，并优化完整提交日志写入。保留 Ninja Adventure 美术和原有玩法规则。

`GODOT-LICENSE.txt` 为 Godot 的 MIT 许可，`GODOT-THIRD-PARTY.json` 记录引擎第三方组件许可。Ninja Adventure 采用 CC0，授权与作者说明随包提供。按钮声音由程序生成，无额外音频素材。`SHA256SUMS.txt` 可用于核对包内文件，`build_manifest.json` 记录候选版本、引擎和内容指纹。

候选包带有专用 QA 诊断入口；仅显式启用时运行，写入限制在 EXE 旁 `qa/p8-export-*`。常规测试场景、验证档案与工具未放入发布 PCK，交付 ZIP 不包含本机 QA 输出。
