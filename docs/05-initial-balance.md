# 首版数值与内容配置

更新：2026-10-15。版本：0.2，单机基数沿用 0.1。状态：P3–P6 生存 / 身体 / 技能 / 战斗及 P6.5 完整合作已实现；资源 / 危险倍率、个人成长与逐人奖励按出发人数 / 执行者计算，个人容量与身体参数不放大。静态配置位于 `data/survival_content.tres`、`data/health_config.tres`、`data/skill_catalog.tres`、`data/combat_config.tres`，合作实现见 [P6.5 报告](17-p65-implementation.md)。P7 已完成路线控制实验与采购复核，依据见第 12 节；本轮保留七日目标、默认消耗、价格、培训及奖励。

本文数值可直接用于实现，但不是实测平衡结论或医学数据。调参必须记录版本、原因和验证结果。玩法规则以 [已确定设计决策](03-design-decisions.md) 为准。

放置同时检查占格边界、重叠、内容升数和总重量。物品可 90° 旋转，R 切换朝向，鼠标拖放，Shift + 点击弹出拆分数量面板；无自动丢物或自动挤走其他物品。首版不允许背包嵌套，固定水容器内容除外。

总重量 `W` 包含背包空重、装备和容器内容，30 kg 为硬上限。令 `f = clamp((W - 18) / 12, 0, 1)`，移动倍率 `1 - 0.35f`，高强度体力开销倍率 `1 + 0.75f`。出发、拾取、取水或改变装备后均不能超上限，失败操作完整回滚。

体积与格子不一一换算。堆叠固定占格，重量 / 体积按数量相加；工具和水容器不堆叠。食物合并时采用最早到期时间；拆分继承该时间。水壶外部体积固定，内部水量影响重量，不重复计外部体积；水重量为 1 kg/L。水只能与相同净化状态的水合并，剩余容量不足时转移明确选择的部分量。

## 4. 营养、水分与健康

五类营养按碳水、脂肪、蛋白质、矿物质、维生素顺序。每游戏小时基础消耗 `(4, 1.5, 2, 1.2, 1)`；睡眠前两项 ×0.5、蛋白质 ×0.75，劳动 / 冲刺前两项 ×1.5、蛋白质 ×1.1，后两项不加活动倍率。

水分每游戏小时基础 -4，睡眠 -2，劳动 / 冲刺 -6；肠胃不适额外 -2。0.5 L 清水 +25，饮水动作 1 游戏分钟，可按 0.25 L 一档调整饮量。泉水可无容器直接饮用；河湖水可直接喝但按生水风险处理，显示风险提示。

营养或水分 <30 时提示；每个营养 <20 时健康每小时 -1，五项合计最多 -4；水分 <20 时另 -2。营养恢复 ≥30 后停止对应健康扣减，20–30 之间保留不足状态；水分恢复 ≥30 后解除脱水。水分为 0 血量每小时 -6。碳水与脂肪同时 <10 持续 2 小时后血量每小时 -3，任一恢复 ≥20 时停止。

安全休息时且水分 ≥40、所有营养 ≥30、无出血 / 肠胃不适，健康每小时 +0.5。血量基础每小时 +2，乘营地系数及 `min(1, 蛋白质/50, 健康/60)`；衰弱再 ×0.7。非休息不被动回血。健康为 0 不直接死亡。

食物在 10 游戏分钟内线性消化，封顶 100，并行消化不保存溢出。单机菜单暂停也暂停腐坏；合作个人菜单不暂停，消化 / 腐坏由房主继续模拟。

P3 补充的基础交互默认值：进食一份 1 分钟 / 0 体力，添一份燃料 1 分钟 / 0 体力；煮水耗时按 1 L / 10 分钟线性缩放，体力 2，水壶内生水全部煮净，避免半壶清水与生水混装。水量可按 0.25 L 一档选择。P4 已接入污染发病。饥饿触发前低于 10 的两小时必须连续，达到 10 会打断触发计时；触发后 10–20 之间保留饥饿，达到 20 解除。

## 5. 体力与行动费用

体力速率统一为游戏分钟：冲刺 -4，普通移动消耗 -0.25 且可恢复 +1，静止 +2，安全休息 +4。高强度动作执行中不恢复，睡眠恢复封顶 100。

恢复乘 `clamp(min(碳水/40, 水分/40, 健康/60), 0.25, 1)`；衰弱再 ×0.7。高强度费用乘负重倍率。零体力不扣移动费用、仍按普通移动规则恢复，保留慢走、饮食和休息，不能冲刺或开始体力不足的劳动。

离散劳动开始时一次扣体力，过程中不再次扣同一劳动费；营养 / 水分按劳动速率持续消耗，结束后恢复普通规则。取消不退体力 / 已花时间，释放未消耗的锁定材料。制造产物放不下时保留在当前工作点的可领取输出区，不能丢失或重做刷产出。

## 11. 存档、返仓与验证

单机一个完整档案槽，永久 / 单局 / 结算同事务，临时文件写完再替换，备份仅损坏恢复。每 2 现实分钟、关键转换、日切换和正常退出保存；单机暂停不累计周期存档间隔。合作房主保存世界、个人保存基地成长，以跨端提交 / 收据去重，个人菜单期间世界 / 存档时钟仍推进。

保存地图、随机状态、动物、陷阱、火源、食物到期、消化、疾病计时、动作进度、资源锁定、物品布局 / 旋转 / 内容。任务 ID 防止重复奖励和返仓。数据恢复校验 ID、数量、占位和容量，无效数据拒绝加载并尝试恢复备份。

返仓按体积降序、占格面积降序、实例 ID 升序，先原朝向后旋转，以从上到下、从左到右首个合法格放入；不合适者进入无到期 / 无截断的持久化待领取区，必须入仓才能使用，不提供无限随身容量。领取或卖货不在基地推进荒野时间。

验收用 100 个固定种子验证地图，至少 5 个种子正常速度完成任务试玩。检查三条食物路线、零货币重新出发、零体力恢复、满仓返航、同刻死亡、睡眠、重复结算、存档恢复和低耦合 / 注释。
